# Ejercicios con pandas

Ejercicios de manipulación y análisis de datos con pandas sobre un dataset de notas de
estudiantes (`estudiante.csv`).

## Archivos

- `ejercicio.py`: versión inicial con listas y diccionarios puros (sin pandas).
- `ejercicio1.py`: cálculo de promedios, mejor y peor promedio del curso.
- `ejercicio2.py`: cantidad de estudiantes que aprobaron todas las asignaturas.
- `ejercicio3.py`: moda de las notas.
- `ejercicio4.py`: porcentaje de estudiantes con notas bajo 4.0.
- `ejercicio5.py`: estudiantes ordenados por promedio.
- `validadores.py`: validación y limpieza básica de datos antes de procesarlos.

## Uso

```bash
pip install pandas
python ejercicio1.py
```
